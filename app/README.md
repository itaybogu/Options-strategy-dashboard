# Welcome to RoboQuant Trading Development Platform!

## Your Workspace Structure:
- /workspace/strategies/ - Your trading strategies
- /workspace/indicators/ - Custom indicators
- /workspace/backtest/ - Backtesting scripts

## Getting Started:
1. Create new files using the File Explorer
2. Edit them in the code editor
3. Run Python scripts: python script.py
4. Install packages: pip install package_name

## Available Languages:
- Python 3.12
- PineScript (for TradingView)
- More coming soon...

Happy coding! 🚀
